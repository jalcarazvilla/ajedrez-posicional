# Ajedrez: Entrenador Posicional

Entrenador de ajedrez para aprender a pensar en planes, estructuras y evaluación con cientos de posiciones de partidas de grandes maestros.

**Pruébalo:** https://jalcarazvilla.github.io/ajedrez-posicional/

En el móvil, abre el enlace y elige **"Añadir a pantalla de inicio"** para usarlo como una app (funciona sin conexión).

## Modos

- **Encuentra el plan:** elige el mejor plan o juega tu jugada en el tablero; Stockfish la valora.
- **Adivina la jugada:** juega las jugadas del maestro y compara las tuyas con Stockfish.
- **Evalúa:** verdadero o falso sobre la posición y quién está mejor.

Elo con multiplicador por racha, problema del día y ranking global.
